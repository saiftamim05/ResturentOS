
# RestaurantOS

## Project Name
RestaurantOS - Restaurant Management System

## Project Purpose
To build a complete restaurant management system.

## Main Features
1. Admin Dashboard
2. Employee Management
3. Customer Management
4. Table Booking
5. Food Menu Management
6. Order Management
7. Billing System
8. Inventory Management
9. Sales Reports
10. User Login and Registration

## User Roles
- Admin
- Manager
- Employee
- Customer

## Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Python
- Database: To be decided

## Project Goal
To develop a professional restaurant management system.
